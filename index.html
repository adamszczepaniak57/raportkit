FAQ

Najczęstsze pytania

Czy muszę dawać dostęp do panelu admina WooCommerce?
Nie. Używamy wyłącznie klucza API z uprawnieniami tylko do odczytu (read-only). Nie możemy nic zmienić w Twoim sklepie — tylko odczytywać dane sprzedażowe.
Jak długo trwa konfiguracja?
Zwykle 3–5 minut. Wpisujesz adres sklepu, generujesz klucz API w WooCommerce (mamy instrukcję krok po kroku), wklejasz go w formularzu. Gotowe — pierwszy raport dostaniesz w ciągu 24h.
Czy działacie z Shopify?
Tak, obsługujemy WooCommerce, Shopify oraz PrestaShop. Jeśli korzystasz z innej platformy — napisz do nas, jesteśmy w trakcie dodawania kolejnych integracji.
Co jeśli będę chciał zrezygnować?
Anulujesz subskrypcję jednym kliknięciem w panelu klienta. Bez rozmów, bez formularzy, bez okresu wypowiedzenia. Dostęp kończy się z datą ostatniej opłaty.
Czy moje dane sprzedażowe są bezpieczne?
Tak. Dane przesyłamy szyfrowanym połączeniem HTTPS, nie przechowujemy danych zamówień ani danych klientów Twojego sklepu — tylko zagregowane statystyki potrzebne do raportu.
